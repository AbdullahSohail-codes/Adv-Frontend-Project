# 🎬🎮 Watchlist

Watchlist is a personal tracking app where you can save movies and games you want to watch or play later. No more forgetting that recommendation a friend gave you — just add it to your list and come back to it anytime.

## Features
- Add movies and games to your personal list
- Separate categories for movies and games
- Mark items as watched / played
- Remove items you're no longer interested in
- Keep everything saved for later use

## Purpose
Built to make it easy to keep track of entertainment you don't want to miss, while practicing CRUD operations and data persistence.
